    이 화면을 읽는 방법과 모델 경계

    153의 주소 선택은 항상 A_bit + 2 × B_bit입니다. LGC와 BCTRL은 4개 데이터 입력의 진리표이며, 피연산자 선택을 대체하지 않습니다. 283 두 개는 C_LO로 연결되고, 157은 SUM 또는 LOGIC을 Y로 보냅니다.

    C_HI는 논리 연산 중에도 물리 가산기의 자리올림입니다. SUB / CMP에서만 부호 없는 A ≥ B로 해석합니다. CMP는 결과를 계산해도 ACC에 쓰지 않으며, NOP의 물리 Y=A와 CPU 상태 유지는 구분됩니다.

    iterations는 안정화 패스 수이며 CPU 클록이나 시간 지연이 아닙니다. 게이트·전체 구조 화면은 기능 연결이며, 실제 DIP 핀 번호와 연결표는 칩 배선도 탭에서 확인합니다. 타이밍과 물리 장착은 별도 검증 대상입니다.
